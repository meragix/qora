`CancelToken` est un signal d'annulation coopératif à usage unique. Le passer à `fetchQuery`, `watchQuery` ou `prefetch` et appeler `cancel()` pour interrompre le fetch avant son démarrage ou pendant son exécution.

---

## Créer un token

```dart [main.dart]
final token = CancelToken();
```

Un token ne peut être annulé qu'une seule fois. Appeler `cancel()` une deuxième fois est sans effet.

---

## Annuler un `fetchQuery`

```dart [user_repository.dart]
final token = CancelToken();

// Démarrer le fetch
final future = client.fetchQuery<User>(
  key: ['users', userId],
  fetcher: () => api.getUser(userId),
  cancelToken: token,
);

// L'annuler (ex. l'utilisateur a navigué ailleurs)
token.cancel();

try {
  final user = await future;
} on QoraCancelException catch (e) {
  // e.key est la clé de requête encodée en chaîne
  print('Fetch annulé : ${e.key}');
}
```

Quand annulé, `fetchQuery` lève `QoraCancelException` à l'appelant et restaure l'entrée de cache à son snapshot pré-fetch (aucun état partiel n'est laissé derrière).

---

## Annuler un stream `watchQuery`

```dart [user_page.dart]
final token = CancelToken();

final sub = client.watchQuery<User>(
  key: ['users', userId],
  fetcher: () => api.getUser(userId),
  cancelToken: token,
).listen((state) { ... });

// Au dispose du widget : annuler le fetch en cours
token.cancel();
await sub.cancel();
```

:::tip
Annuler l'abonnement au stream est distinct de l'annulation du fetch. `token.cancel()` interrompt la requête HTTP ; `sub.cancel()` retire le listener d'état. Faire les deux au dispose pour un nettoyage propre.
:::

## Pattern de timeout

Combiner `CancelToken` avec `Future.delayed` pour implémenter un timeout de requête :

```dart [user_repository.dart]
Future<User> fetchWithTimeout(int userId, Duration timeout) async {
  final token = CancelToken();

  Timer(timeout, token.cancel);

  try {
    return await client.fetchQuery<User>(
      key: ['users', userId],
      fetcher: () => api.getUser(userId),
      cancelToken: token,
    );
  } on QoraCancelException {
    throw TimeoutException('Fetch utilisateur expiré après $timeout');
  }
}
```

## Annulation à la navigation dans Flutter

Dans un `StatefulWidget`, lier le token au cycle de vie du widget :

```dart [user_screen.dart]
class _UserScreenState extends State<UserScreen> {
  CancelToken? _fetchToken;

  Future<void> _loadUser() async {
    _fetchToken = CancelToken();
    try {
      await context.qora.fetchQuery<User>(
        key: ['users', widget.userId],
        fetcher: () => api.getUser(widget.userId),
        cancelToken: _fetchToken,
      );
    } on QoraCancelException {
      // Widget disposé : ignorer
    }
  }

  @override
  void dispose() {
    _fetchToken?.cancel();
    super.dispose();
  }
}
```

## API `CancelToken`

### Constructeur

```dart
CancelToken()
```

### Propriétés

| Propriété     | Type   | Description                                  |
| ------------- | ------ | -------------------------------------------- |
| `isCancelled` | `bool` | `true` après l'appel à `cancel()`.           |

### Méthodes

| Méthode    | Signature | Description                                                                |
| ---------- | --------- | -------------------------------------------------------------------------- |
| `cancel()` | `void`    | Marque le token comme annulé. Idempotent et sûr à appeler plusieurs fois.  |

---

## `QoraCancelException`

Levée par `fetchQuery` et `prefetch` quand un fetch est annulé via `CancelToken`.

```dart
class QoraCancelException implements Exception {
  final String key; // clé de requête normalisée encodée en JSON
}
```

| Propriété | Type     | Description                                            |
| --------- | -------- | ------------------------------------------------------ |
| `key`     | `String` | La clé de requête encodée en chaîne, ex. `'["users",1]'` |

---

## Hook du tracker

`QoraTracker.onQueryCancelled(String key)` est appelé chaque fois qu'un fetch est annulé via `CancelToken`. L'implémenter sur un tracker personnalisé pour journaliser ou mesurer les taux d'annulation :

```dart [analytics_tracker.dart]
class AnalyticsTracker extends NoOpTracker {
  @override
  void onQueryCancelled(String key) {
    analytics.track('query_cancelled', {'key': key});
  }
}
```
